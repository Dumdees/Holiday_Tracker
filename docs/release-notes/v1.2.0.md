## Monteith Holiday Manager 1.2.0

**New: Care Empire**, a light-hearted tea-break game in the menu. Click a carer to do visits, collect the payments, then hire your real team, buy care cars, rota apps, offices and hubs, and grow from one street to the whole world (and beyond). Expanding to the next stage starts the run again but earns Legacy Stars that make everything faster, forever. Watch out for prismatic carers and thank-you cards, collect achievements, and your team keeps working while the app is closed.

The game is completely separate from your real holiday records. Hide it any time under *Settings → General*.

**To install or update:** download the file ending in **Setup.exe** below and double-click it. It updates an existing copy in place.
