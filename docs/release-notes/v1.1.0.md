## Monteith Holiday Manager 1.1.0

**The app now opens in its own window.** Version 1.0 relied on Microsoft Edge to show the app, and on some computers Edge showed only a blank window. The app is now a proper Windows program with its own icon and window.

**To install:** download the file ending in **Setup.exe** below, double-click it and click Next until it finishes. A *Monteith Holiday Manager* icon appears on your Desktop and in the Start menu. If Windows says "Windows protected your PC", click *More info* then *Run anyway*.

**If you used version 1.0 and had already entered carers:** open the old version (the file `Monteith Holiday Manager.html`) in your browser, go to *Settings → Backup → Save a backup file*, then in the new app use *Settings → Backup → Restore from a backup file*.

Everything stays on your computer; nothing is sent over the internet.
