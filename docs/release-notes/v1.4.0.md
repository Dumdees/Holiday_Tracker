## Monteith Holiday Manager 1.4.0

**New: shift patterns.** Some carers work every other weekend, or a rota that repeats every three or four weeks. When adding or editing a carer, choose *Repeats every 2 weeks* (or 3 or 4), tick the days for each week and say which week the current week is. There is a one-click fill for the usual alternate-weekends pattern. From then on:

- Holidays only use up days on the days that carer would really have worked, week by week.
- Clash warnings about staffing and pairings only count someone on the days they would have been in, so a carer on their weekend off no longer looks like a gap.
- The carer's profile shows the pattern, which week it is this week, and greys out their days off on the year calendar.
- Spreadsheet exports and imports carry the pattern ("Week 1: Mon–Fri / Week 2: Wed–Sun").

The sample data now includes two carers on opposite alternate-weekend patterns.

**To install or update:** download the file ending in **Setup.exe** below and double-click it. It updates an existing copy in place.
