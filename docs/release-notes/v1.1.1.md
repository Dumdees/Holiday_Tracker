## Monteith Holiday Manager 1.1.1

Fixes "the app couldn't start – an attempt was made to load a program with an incorrect format" on some computers. Version 1.1.0 only included one flavour of a small Windows helper file; this version includes the flavour for every kind of Windows PC, including ARM-based laptops.

**To install or update:** download the file ending in **Setup.exe** below and double-click it. It updates an existing copy in place – there is no need to remove the old one first. If Windows says "Windows protected your PC", click *More info* then *Run anyway*.

**If you used version 1.0 and had already entered carers:** open the old version (the file `Monteith Holiday Manager.html`) in your browser, go to *Settings → Backup → Save a backup file*, then in the new app use *Settings → Backup → Restore from a backup file*.
